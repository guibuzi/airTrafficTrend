# Air Traffic Trend

## Overview
This project analyzes air traffic trends and visualizes key metrics over time. It can be used to explore historical traffic patterns, identify peak periods, and compare regional or route-level activity.

## Features
- Import and process air traffic data
- Generate trend charts and summary statistics
- Export reports or visualizations
- Adjust input data paths and configuration in the project files as needed.

## Project Structure
- `data/` - input datasets
- `processed_data/` - input datasets
- `processed_big_data/` - input datasets
- `src/` or `scripts/` - processing and analysis code
- `notebooks/` - exploratory analysis
